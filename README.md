# SAYKO Website Source

This is a standalone copy of the custom SAYKO website code retrieved from the Apper project.

## Run locally
1. Install Node.js (LTS).
2. Extract this ZIP.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL Vite prints (usually http://localhost:5173).

## Included
- Interactive entrance screen (HIM/HER character selection)
- CSS storefront and showroom
- Product drop/category filters
- Product detail modal
- Shopping bag
- WhatsApp checkout link placeholder
- Custom Lab section and brand manifesto

Note: This standalone package contains the custom website source and a lightweight Vite setup. It does not include Apper's platform-managed backend/authentication boilerplate.
